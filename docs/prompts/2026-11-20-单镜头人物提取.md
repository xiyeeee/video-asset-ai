在现有 video-asset-ai 项目中，实现「单镜头人物提取」CLI。复用已有的 FFmpeg 抽帧逻辑和 frames.json。\
\
1\. 从 frames.json 读取指定截图及其 timestampMs。支持选取一张或多张截图进行验证。\
2\. 用 Grounding DINO 检测人物，输出带框调试图。每个检测框记录像素坐标和检测分数。\
3\. 用 SAM 2 对每个人物框做独立分割，导出带透明通道的 PNG。\
4\. 输出 characters.json。每条记录包含来源截图、timestampMs、人物框、检测分数和透明 PNG 的相对路径。人物编号只在当前截图内有效。\
5\. 模型依赖和权重按实际实现引入。先检查 Python 3.11 和本机 Apple Silicon 的兼容性，在 README 记录实际运行设备、权重配置和 CLI 命令。\
6\. 用真实漫剧的清晰同框帧和轻度遮挡帧验收。分别检查有没有漏框、有没有把两人框成一个，以及抠出的 PNG 有没有带进旁边的人。缺少真实样片时，明确记录哪些效果还未验证。\
\
本轮范围是截图输入、人物检测、分割和透明 PNG 导出。验收时，同一张清晰截图里的两个人应各自导出一张透明 PNG，两张图都能追溯到原视频的同一时刻。完成后运行 Ruff 和相关测试，并给出实际生成的调试图与结果路径。\
\
将本轮收到的完整提示词原样保存到当前项目的 docs/prompts/ 文件夹，文件夹不存在就创建，文件名使用 YYYY-MM-DD-单镜头人物提取.md，保留已有记录，同名时追加序号。
