# Python 按分镜提取背景开发提示词

在 `video-asset-ai` 实现 `BACKGROUND` 分支。先读 `AGENTS.md`、[背景三端契约](../background-extraction-contract.md)、现有分镜、代表帧提取及人物检测代码。按契约完成 Python 端，保留已有分镜和其他素材接口。

## 实现范围

1. 从已有 `shots.json` 获取镜头区间。依契约支持显式分镜引用、同任务复用 `SHOTS` 产物，以及只提背景时复用分镜检测形成时间区间。分镜失败时保持错误可定位，避免后台依赖互相占用同一执行线程。
2. 每个镜头从原视频选少量实际帧作为候选，保留真实 PTS。短镜头允许只取一张。避免将不同镜头的画面混入同一个候选组，画面和时间保持一致。
3. 复用人物检测，按遮挡少、画面清晰等可解释规则挑选一张图。画面字幕检测有可用能力时复用；缺少检测证据时写 `UNKNOWN`。用契约中的状态诚实标记候选。首版产物是原帧 JPEG。
4. 输出 `backgrounds.json` 和候选图，校验目录、实际文件、镜头范围后原子发布。复用状态及日志，人物推理与现有任务共享受控的模型执行资源。

## 本端检查

运行 Ruff 检查、格式检查及 pytest。覆盖清单复用、短镜头与 PTS、无人物、字幕未知、遮挡标记、路径越界和同单依赖失败。这一阶段直接按契约实现，无需等待 Java 和前端。

## 收到通知后集中验收

用真实漫剧跑 `BACKGROUND`，优先核对《末班车之后》的较空画面、两人同框和烧录字幕画面。交付实际清单、图片、任务 ID 和来源时间，说明哪些图为待复核。再与 Java、前端用同一集核对。
